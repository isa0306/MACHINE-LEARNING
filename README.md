# MACHINE-LEARNING
Um pequeno pórtifolio sobre a matéria da faculdade "machine learning"


Está matéria serve para basicamente a mostrar como ensinar a máquina a criar seu algoritmo de acordo com o aprendizado que daremos, 

-PROBLEMAS DE MACHING LEARNING-

-> FORMULAÇÃO DE PROBLEMAS 
O primeiro aprendizador é saber determinar os elementos T P e E.
O exemplo dado foi um programa de jogar damas.
T= jogar damas
P porcentafem de desempenho = porcetagem de vitorias contra o adversario
E= jogar partidas contra si mesmo
